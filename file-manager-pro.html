File Manager Pro Privacy Policy

Developer: [DEVELOPER NAME]

Effective date: 23 November 2026

Files and information accessed

File Manager Pro accesses files and folders that Android makes available to the app so you can browse, search, preview, organize, copy, move, rename, delete, and share files, as well as create ZIP archives and extract files from archives.

To provide these features, the app reads file metadata such as file and folder names, locations, sizes, types, and modification dates. Favorites you choose are saved locally on your device.

Android storage permissions

On supported Android versions, All files access allows File Manager Pro to manage files across shared storage. Android controls this permission, and you can allow or revoke it in Android Settings.

The Android system folder picker gives File Manager Pro access only to folders you select through that picker. On older Android versions, the app uses legacy storage permissions to access shared storage.

Copy, move, ZIP creation, and extraction tasks that you start can continue while the app is in the background. If you allow notifications, File Manager Pro can show the task's progress and a Cancel action in a notification.

Collection, transmission, and secure handling

File Manager Pro has no Internet permission and does not use a developer backend, app accounts, advertising, analytics, or crash-reporting SDKs. The app performs its own file operations on your device. The developer does not receive copies of your files or file metadata through the app.

Android controls the app's access to files through storage permissions and the system folder picker. You decide whether to grant All files access and which folders to make available through the folder picker.

User-initiated sharing and third-party providers

When you choose to share a file through Android's share menu or open it in another app, the receiving app may process that file under its own privacy policy. File Manager Pro initiates the transfer you request; it does not control how the receiving app handles the file.

If you select a folder from a third-party document provider, including a cloud storage provider, File Manager Pro can work with the files that provider makes available through Android's folder picker. The third-party provider may process or sync those files under its own privacy policy. File Manager Pro itself performs the file operations you request on the device and does not operate the provider's service.

Retention, deletion, and your controls

The developer does not retain your files or file metadata on a server. You can remove locally saved favorites within the app. You can also revoke All files access in Android Settings.

Android's Clear storage option removes File Manager Pro's local app settings and favorites. Clearing the app's data does not delete your documents in shared storage and does not remove copies you have already sent to other apps.

If you manage files supplied by a third-party document provider, the provider controls its own storage, syncing, retention, and deletion practices. Refer to that provider's privacy policy and account controls for details.
